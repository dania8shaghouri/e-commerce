# Full-Stack E-Commerce Web Application

A full-stack e-commerce application developed with React, TypeScript, Node.js, Express.js and MongoDB.

This project includes user authentication, role-based authorization, product management and an admin dashboard structure.

## 🚀 Live Demo

[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge)](https://ecommerce-frontend-lyart-one.vercel.app/)

## Features

- User registration and login
- JWT based authentication
- Role-based authorization (Admin / Customer)
- Product listing
- Product detail pages
- Admin dashboard
- Product management
- RESTful API architecture
- Responsive user interface

## Technologies

### Frontend

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- JWT Authentication
- RESTful API

## Installation and Setup

Clone the repository:

```
git clone https://github.com/dania8shaghouri/e-commerce.git
```

Backend
```
cd backend
npm install
npm run dev
```
Create a .env file:
```
MONGODB_URI=
JWT_SECRET=
```

FRONTEND
```
cd frontend
npm install
npm run dev
```
